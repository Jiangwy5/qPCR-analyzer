直接粘贴

可从 Roche 软件或 Excel 直接复制。首行应为列名；支持 Tab、逗号或分号分隔。

上传 Excel / CSV

支持 .xlsx / .xls / .csv，并兼容 Roche 导出的 All Data / Statistic Data 表；会优先选择逐孔 Ct/Cq 数据。可一次选择多个文件：每个文件自动建立为独立 96 孔板并合并分析。单文件仍可手动确认列映射和工作表。

确认列映射

系统会自动猜测列名；你可以手动修改。已兼容 Roche 常见字段：Cq Mean → Ct/Cq、Sample Name → Sample、Gene Name → Target、Replicate Group Members → Well。若没有 Well，将按导入顺序依次放入 A1–H12。

计算原则（摘要）

标准模式保留 ΔCt = Ct(target) − mean Ct(reference)、2^-ΔCt、ΔΔCt、2^-ΔΔCt 和 log2FC = −ΔΔCt。对照基准为该目的基因所选校准组的 biological replicates（生物学重复）平均 ΔCt。
